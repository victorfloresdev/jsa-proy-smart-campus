# SmartCampus - Frontend (Angular)

Este proyecto fue generado con [Angular CLI](https://github.com/angular/angular-cli) versión 19.2.27.

## Requisitos previos

- Node.js (v18 o superior recomendado)
- npm (v9 o superior)

## Instalación de dependencias

```bash
cd frontend
npm install
```

## Servidor de desarrollo

Para iniciar el servidor local de Angular:

```bash
npm start
# o alternativamente:
# npx ng serve
```

Navega a `http://localhost:4200/`. La aplicación se recargará automáticamente si cambias algún archivo fuente.

## Compilación (Build)

Para compilar el proyecto para producción:

```bash
npm run build
```

Los artefactos compilados se almacenarán en el directorio `dist/smart-campus`.

## Ejecución de pruebas unitarias

Para ejecutar pruebas unitarias con Karma:

```bash
npm test
```
